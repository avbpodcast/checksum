SHA-256 is the one to send. BLAKE2b-512 is the usual BLAKE file checksum, the same digest as b2sum (RFC 7693). BLAKE3 is the 256-bit digest from b3sum. SHA-512 and MD5 are only for older checksum files. MD5 does not prove a file was not swapped.
